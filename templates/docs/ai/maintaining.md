# Maintaining the AI setup

## Where things live

| Path | What | Loaded by |
|---|---|---|
| `AGENTS.md` | Rules every agent follows | Cursor, Codex, most agents; Claude Code through `CLAUDE.md` (`@AGENTS.md`) |
| `.claude/agents/*.md` | Subagent definitions | Claude Code; Cursor (Claude compatibility) |
| `.claude/skills/*/SKILL.md` | Skills, invokable as `/name` | Claude Code; Cursor (Claude compatibility) |
| `.claude/settings.json` | Test-lock hook, `worktree.baseRef: "head"` | Claude Code; Cursor imports its hooks too |
<!-- @if cursor=yes -->
| `.cursor/hooks.json` | Same test-lock hook, native Cursor format | Cursor |
<!-- @endif -->
| `.claude/commands/opsx/`, `.cursor/commands/`, `.cursor/skills/openspec-*` | OpenSpec workflows | Generated by `openspec init`; don't edit by hand |
| `scripts/agent-hooks/block-test-edits.mjs` | The hook itself | Both tools |
| `openspec/config.yaml` | Project context and artifact rules for OpenSpec | OpenSpec CLI and skills |
<!-- @if graph=graphify -->
| `graphify-out/` | Knowledge graph | `graphify query`, the graphify skill |
<!-- @endif -->

<!-- @if cursor=yes -->
There is one copy of each agent and skill. Don't duplicate them into `.cursor/`: a same-named file there wins over
`.claude/` in Cursor and the two drift apart.
<!-- @endif -->

## Keep AGENTS.md short

A 2026 evaluation of context files ([Evaluating AGENTS.md](https://arxiv.org/abs/2602.11988)) found that repository
overviews and directory listings don't help agents and raise cost by about 20 %; only non-obvious requirements
help. So `AGENTS.md` holds constraints, commands, the definition of done and pointers, nothing an agent can find by
reading the code. When you add a line, remove what it supersedes. Longer explanations go in `docs/`.

## Adding or changing an agent

1. Create `.claude/agents/<name>.md` with frontmatter both tools understand:

   ```yaml
   ---
   name: my-agent                 # lowercase, hyphens
   description: When to delegate to it (both tools read this to decide)
   model: inherit
   readonly: true                 # Cursor only; omit for agents that run commands or edit
   disallowedTools: Edit, Write   # Claude Code only
   isolation: worktree            # Claude Code only
   ---
   ```

   Each tool ignores the other's fields.
2. Write the prompt: inputs, method, an exact output format, and the rules. Keep agents single-purpose.
3. List it in [agents.md](./agents.md) and, if the loop uses it, in the `task` skill.

## Pinning a model

Shared files use `model: inherit`. To pin one, set `model: sonnet|opus|haiku` (or a full model ID) in the agent's
frontmatter.
<!-- @if cursor=yes -->
Cursor expects its own model IDs and fails to resolve Claude Code aliases, so for agents Cursor users also run, copy
the agent to `.cursor/agents/<name>.md` with a Cursor model ID instead. Cursor uses that copy and Claude Code keeps
the shared one; keep the prompts in sync.
<!-- @endif -->

## Adding a skill

Create `.claude/skills/<name>/SKILL.md` with `name` and `description` (the description decides when it triggers).
Add `disable-model-invocation: true` for skills that should only run when a user types `/name`. Put long reference
material in `references/` next to it instead of in `SKILL.md`.

## The test-lock hook

`block-test-edits.mjs` reads the lock files `openspec/changes/*/locked-tests.txt` and `.loop/*/locked-tests.txt`
from the current checkout and from the main checkout (so it works inside linked worktrees). It blocks:

- edits to a locked path, by any agent;
- in Claude Code (the payload names the agent): `developer` editing any test file, `test-writer` editing a
  non-test file (what counts as a test file is the `TEST_FILE` pattern at the top of the hook);
- shell commands that modify a locked path, or `git reset --hard`, `git stash`, `git checkout .`,
  `git restore .`, `git clean -f` while any lock is active.

Test it by piping a payload:

```bash
echo '{"tool_name":"Edit","agent_type":"developer","tool_input":{"file_path":"'$PWD'/{{EXAMPLE_TEST_PATH}}"},"cwd":"'$PWD'"}' \
  | node scripts/agent-hooks/block-test-edits.mjs; echo "exit $?"   # exit 2 = blocked
```

To unblock a stuck task deliberately, edit the lock file yourself; agents shouldn't.

## Updating the tooling

- OpenSpec: `openspec update` regenerates the `openspec-*` skills and `/opsx` commands for Claude Code and Cursor.
<!-- @if graph=graphify -->
- graphify: `graphify update .` after structural changes (the `/task` loop runs it after archiving).
